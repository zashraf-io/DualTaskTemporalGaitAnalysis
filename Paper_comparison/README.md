# Paper Comparison

This module compares the Dual-Task Cost (DTC) results generated by our pipeline against the original DUO-Gait dataset paper results.

## Overview
It reads the aggregated parameter files from the DUO-Gait paper dataset and computes their Dual-Task Cost. Then, it compares these values against the DTC values output by our pipeline (`master.csv`). It calculates the Mean Absolute Error (MAE) for the DTC of each gait parameter across matching participants.

## Requirements
Ensure you have the required packages installed:
```bash
pip install pandas numpy pyqtgraph PyQt6
```

## Usage
Run the comparison GUI script:
```bash
python compare_results.py
```

### Features:
- **GUI Visualization**: Displays grouped bar charts comparing our Average DTC vs Paper Average DTC per parameter using `pyqtgraph`.
- **Error Percentage Table**: Shows the error percentage (Mean Absolute Error) between the two methods.
- **Auto-save**: Automatically saves the comparison graphs as PNG files in this directory.
